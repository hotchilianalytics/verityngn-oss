# Risk lexicon

**Date:** 2026-08-14  
**Rule:** Prefer risk measurement language everywhere a pitch, panel, or API name would otherwise say “signal” or “alpha.”

---

## Substitution map

| Avoid / retire | Prefer |
|----------------|--------|
| signal (product noun) | **risk factor** |
| Signal API | **Risk Factor API** |
| farm signals | **measure risk factors** |
| delivery signal / alpha-adjacent | **delivery risk measurement** |
| corpus signal report | **player risk panel** (keep filenames; change headings) |
| signal sleeve / finance sleeve (when pitching risk) | **risk assessment / abatement sleeve** |
| promote / alpha (before gates) | **NO_PROMOTE** = *risk factor not validated for allocation* |
| lie detector / deception / tells | congruence · delivery-risk · disclosure-risk |
| truth score / per-video % | categorical verdicts only |

---

## Sleeve framing (spoken or written)

VerityNgn-OSS = **claim index**. VerityIndex verticals on top = **risk assessment and abatement sleeves**:

| Sleeve | Risk job |
|--------|----------|
| Finance / delivery | Delivery-consistency, venue prior, instrument risk — before trusting a market join |
| Brand safety | Sponsor / brand-reputation risk — certify claims before spend |
| Legal video | Evidentiary / authentication risk on A/V |
| GC disclosure (Horner) | Disclosure / governance risk — inventory risk language in quarterly & annual packs |

## Guardrails that survive the rename

1. Congruence / delivery-risk / disclosure-risk only  
2. Never lie detector, deception product, HR, or education screening  
3. Categorical verdicts only on public surfaces  
4. S14 vocal dissonance always ships with near-chance caveat or not at all  
5. **NO_PROMOTE** until ICIR / DSR / n gates pass — risk measurement is allowed at small n; allocation is not
